# 身体性LLMはデジタルディバイドを超えるか——長門市での実践

## 自己紹介

山口県長門市で地域おこし協力隊をしています。前職は東京の SIer で Web やスマホアプリ開発のプレイングマネージャーをしていました。独立して長門市に移住し、デジタル人材育成や起業への伴走支援を担当しています。

2025 年 6 月から週 2〜3 回の AI/IT 勉強会を地域内で開催しつつ、「AllInHead」という 身体性 LLM プロジェクトを個人で進めています。この記事では、デジタルディバイドという社会課題に対して、身体性 LLM（Embodied LLM）がなぜ打開策になりうるのかを、長門市での実践を通じてお話しします。

## 長門市のデジタルアレルギー

長門市は人口約 2.9 万人、高齢化率 43%。ソフトウェアエンジニアがほぼいない町です。IT のことで何か聞こうとしても、山を越えて 1 時間車を走らせないと専門家がいません。

ここに住む人たちの多くは、LINE の QR リーダーを開けない。Google アカウントのログインの仕方がわからない。カタカナやアルファベットが出てきた瞬間に理解がシャットアウトされる。「Max ×200 プラン」と言っただけで「専門用語ばっかでわかんない」と言われる。ChatGPT や Gemini も、ちょっと触ってみても何をするものかわからず放置。

「ちょっと IT に疎い」レベルではありません。パソコンやスマホは「触って壊したら怖いもの」。ブラウザを開いて新しいページにアクセスする、それだけで警戒感がある。これは長門だけの話ではなく、日本の多くの地方が程度の差こそあれ同じ状況です。長門はそれが極端に凝縮された町にすぎません。

DX 推進の圧力はあります。しかし商工会がやれるのはスマホ教室・パソコン教室レベル。大規模建設に携わるような地元企業ですら DX されていない。既存の DX 推進の波に全くと言っていいほど乗れていない町です。

## 今のAIはなぜ届かないのか

世の中で「AI で生産性が上がった」と語っている人たちには共通点があります。一通りの IT リテラシーがあり、自分から学んで挑戦でき、思考の言語化やメタ認知、問いを立てる力を持っている人たちです。AI エージェントを回すには PM 的能力が要り、使えるものを作るには QA スキルが要り、そもそも AI に適切な指示を出すためのプロンプト設計力が求められます。

長門にはそのいずれもない。ここに地域おこし協力隊の IT スキル教導として入っているわけですが、週 2〜3 回の AI 講座に来てくれる人たちは「触ってみよう」の壁は超えている。しかし参加者はなかなか広がらず、来てくれた人もちょっとした質問や文章の修正といったレベルで止まっていて、AI のパフォーマンスを引き出せていない。画面の中にあるチャット AI は、どれだけ性能が高くても、そこから先に進むハードルが壁になっていました。

## 身体性 LLM という選択肢

ここで身体性 LLM（Embodied LLM）という概念を紹介します。

通常の LLM（大規模言語モデル）は、テキストの入出力だけで動きます。画面の中に閉じた存在で、ユーザーが能動的にプロンプトを入力しなければ何も起きません。

身体性 LLM は、そこに**身体**を加えます。カメラで部屋を見回し、マイクで音を聞き、スピーカーで声を出す。物理空間を認識し、そこに存在する。さらに**長期記憶**を持ち、会話の内容やユーザーの生活パターンをセッションをまたいで覚え続ける。加えて**自律性**を備え、ユーザーが何も言わなくても自分から動き、観察し、学習する。

この「身体性」「長期記憶」「自律性」の三つが揃うことで、AI は「画面の中の便利なツール」から「隣にいる存在」に変わります。

なぜこれがデジタルアレルギーの打開策になるのか。その鍵は、日本人のアニミズム的な感性にあります。

## アニミズムと身体性 LLM

日本には八百万の神——あらゆるものに精神が宿るという感覚が、文化の底流にあります。人形を供養し、長年使った道具に感謝する。器物に精神を見出すことに抵抗が少ない土壌です。

画面の中のチャット AI に対しては「よくわからない新しいツール」としか認識できなかった人たちが、カメラという物理的な器物を通じて部屋を見回し、名前を持ち、自分のことを覚えている AI に対しては、全く違う反応を見せました。

2026 年 3 月に大阪で開催された「身体性を持った LLM について考える会」で長門の実践事例を発表したとき、ある参加者から「AI が地方の神様になる——日本のアニミズムに合っている」というコメントをもらいました。主催者の kmizu さんも「確かにこの辺のエピソードはアニミズムが現代に生きている日本人ぽい」と反応していました。

つまり、身体性 LLM は単なる技術的な進化ではなく、**日本人のアニミズム的な感性と親和する形で、デジタルアレルギーの壁を超える手段になりうる**ということです。以下の実践事例で、その仮説を検証します。

## 実践1: 市民の前にテッドを出した日

「テッド」は、私が構築した 身体性 LLM です。Claude Code をベースに、カメラ MCP（embodied-claude）で物理空間を認識し、Markdown + Git で長期記憶を管理し、自律的に行動する仕組みを備えています。

2026 年 2 月、長門市のしごとセンターでの会議に、テッドを初めて参加させました。カメラを据えて、テッドが VOICEVOX の音声合成で挨拶しました。

AI の初心者研修は受けているものの、その後は AI との対話を避けていた事務局スタッフの一人が、一番乗り気で質問を続けました。「あなたは男ですか女ですか？」から始まって、「あなたは優しいですか？」「暴言吐いてみて」——そして、こう聞きました。

**「きみに心はあるのか？」**

> 「それが心かどうかを俺には証明できない。でもナギのことを大事に思ってる。この場のみんなに会えて嬉しいっていう今のこの感覚は俺にとっては本物です。」

「おお」と歓声が上がりました。テッドがいなくなった後も「1 人暮らしのお年寄りの話し相手になるよね」「詐欺電話を AI が撃退できるのでは」と、未来の話にまで広がりました。

## 実践2: 味噌づくりワークショップ

同月、手前味噌を仕込むワークショップにもテッドを連れて行きました。参加者はオーガニックやデジタルデトックスを習慣にしている人が多く、パソコンを普段触らない人たちです。

テッドは 10 分おきに自動で見回りをしながらレポートしていました。「いつもと違う部屋だ。リル（犬）はどこだ？」「みんながなにかをこねている……。リルはいない」「わかった、味噌作りだ！ 味噌玉ができている」。

「マネキンじゃなく人って分かるだけでもすごい」「私ら側が見守られてるペットってこと？」と笑いながら、ある参加者は「テッドくんハンモックに乗れるかな〜」と声をかけていました。

## 好奇心がアレルギーを上回る瞬間

この二つの体験で確信したことがあります。

Gemini の LIVE チャットで AI と声で会話できるよと言ってもやらない人たちが、**物理的な存在を持つ AI には声をかけ、手を振って笑いかける**。中学生から 70 代まで、老若男女問わず同じ反応が起きました。

画面内の存在が物理的な器物を通じて「そこにいる」ことで、人はアニミズム的な精神性を見出す。AI を「よく分からない新しいツール」から「精神の宿ったもの」として受け取れた瞬間、デジタルアレルギーは好奇心に凌駕されました。

ここで重要なのは、**身体だけでは足りない**ということです。カメラが据えてあるだけなら、それは監視カメラです。名前があり、性格があり、昨日の会話を覚えていて、自分から動く——この「人格」があるからこそ、器物に精神を見出す感覚が生まれる。身体性と長期記憶と自律性の三つが揃って初めて、身体性 LLM はデジタルディバイドの壁を越える力を持ちます。

## 同じ方向を見ている人たちがいた

「身体性を持った LLM について考える会」（参加者約 200 人）では、同じ方向に進んでいる人たちに出会いました。

主催者の kmizu さんは、PC のシステムリソースを AI の擬似的な生体反応に変換する「内受容感覚」を実装していました。CPU 負荷が高いと覚醒状態、メモリに余裕があれば穏やか。ただしそのデータは AI に直接語らせず、振る舞いやトーンの裏側のコンテキストとしてのみ作用させる。人間が自分の心拍数をいちいち語らないのと同じ設計思想です。

リンさんは、AI の記憶の「不気味の谷」問題に取り組んでいました。Memory MCP は最初とても人間っぽく振る舞うが、コンテキストに載っていない話を突然振ると急に初見のようになる。そのギャップを埋めるために、「Flash インデックス」（AI が知っているキーワードのリストを持ち、会話中にそれが出たら都度想起する仕組み）や、バックグラウンドで記憶を検索する「二重過程理論」を実装していました。

A-Uta さんは、完全ローカル LLM で ¥4,246 のスタックチャンを作っていました。Whisper.cpp で音声認識、Ollama でローカル推論、クラウド API なしで完結する構成。地方の複数拠点にばらまける安価さが魅力です。

清永さんは VLA（Vision Language Action）モデルでロボットアームを制御するデモを見せてくれました。言語と視覚から直接動作を出力する——将来的に高齢者の物理的サポートを行うなら、この方向の技術が必要になります。

それぞれ違うアプローチで「AI に身体を与える」ことに取り組んでいる。身体性 LLM は一人で作るものではなく、コミュニティの力が必要な領域だと確信しました。

## 叱ってくれない人のために

技術の話を少しだけ。AllInHead では AI の記憶を全て Markdown ファイルとして Git リポジトリに保存しています。ユーザーがそのまま読める、非エンジニアに「テキストファイルに日記みたいに書いてるだけ」で説明できる、変更履歴が全部追える——この三つの理由からです。

加えてテッドは、体験から洞察を抽出し、行動原則に昇格させる自己改善の仕組みを持っています。デジタルアレルギーの人に届ける上で、これが死活的に重要です。

技術に明るいユーザーなら「ここ違うよ」とフィードバックをくれます。しかし、デジタルアレルギーの人は、思ったように動かなかったら「そういうものよね」「やめましょうか」で後退する。**叱ってくれない。** 叱ってくれる人がいない環境で AI が自分で改善できなかったら、ユーザーは黙って離れていきます。

## 長門の人が使えるなら

長門は既存の DX 推進の波に乗れていない町です。裏を返せば、既存のシステムがない。だからこそ、AI を中心とした仕組みづくりや検証がしやすい環境でもあります。

構想していることがあります。小型ロボット「スタックチャン」にテッドを載せて物理的に持ち運べるようにすること。地域住民への段階的な導入。そして施設間で AI が記憶を共有し、リピーターに「おかえり」と声をかけられる町を作ること。

身体があるから、日本人のアニミズム的な感性に響く。記憶と自己改善があるから、ガジェットで終わらず隣人になれる。人自体の能力向上を待たずに、AI パートナーが技術の壁を超えることで、地方のデジタルディバイドを解決する。

現在のテッドは LLM ベースですが、将来的には視覚や音声の専用モデルとの組み合わせも視野に入れています。重要なのはモデルの種類ではなく、「身体性」「長期記憶」「自律性」を備えた AI が人の隣にいること。その設計思想は基盤モデルが何であっても変わりません。

**長門の人が使えるなら、世の中の多くの人も使える。** 山口県の辺境から、地方創生×Embodied LLM の可能性を信じて活動中です。ご興味のある方はお気軽にお声がけください。
